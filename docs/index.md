# Technical Notes

This site is a Markdown-first collection of technical notes built with MkDocs Material.

## Sections

- Linux notes for kernel, memory, and filesystem topics.
- C++ notes for language fundamentals and STL usage.
- ROS notes for robotics tooling and workflow references.

## Workflow

To add a new note:

1. Create a Markdown file under `docs/`.
2. Add it to `mkdocs.yml`.
3. Commit and push the change.
